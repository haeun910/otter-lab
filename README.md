# 오터랩 (Otter Lab)

숲속 강가 연구소에서 수달 연구원들이 AI·IT 소식을 모아 **인스타그램 카드뉴스**와 **네이버 블로그 글**을 만드는 작업 공간이에요.
화면은 손그림 강가 지도 한 장이에요. 방을 누르면 그 방으로 다가가고, 사물 버튼을 눌러 일을 확인해요.

### 하루 작업 흐름

1. **수신소 > 수신 모니터**: `새 소식 받기`로 국내외 소식을 받아요 (`src/lab/news/feeds.ts`).
2. 출발 뉴스 1~6개를 담고 `선택한 뉴스로 주제 제안`을 누릅니다. 후보 하나를 골라 제목·설명 범위·조사 질문을 고치고 **주제를 확정**해요. 카드뉴스 한 편에는 주제 하나만 담아요.
3. 자료 도서관의 관련 기사, 읽은 기사에 연결된 공식 문서, 직접 추가한 참고 링크를 조사해요. 확인된 사실과 원문 인용, 읽지 못한 자료를 확인하고 **7장 구성안**의 제목·내용을 고친 뒤 확정합니다. 그때 카드 제작이 시작돼요. 진행 내용은 저장되고 실패한 단계부터 재시도할 수 있어요.
4. **카드뉴스 공방 > 작업 모니터**: 카드 문구·순서, 캡션, 해시태그를 고쳐요. 표지 1 + 설명 5 + 정리 1장이 기본이며, 첫 장은 메인 수달, 나머지는 10종 일러스트를 사용해요. 캡션에 실제 사용한 출처와 고정 인사를 붙이고 해시태그는 5개로 맞춥니다.
5. **카드뉴스 공방 > 인쇄기**: 카드를 1080×1080 PNG로 뽑아요 (카드를 누르면 한 장만). 기존 블로그 원고는 **블로그 서재**에서 계속 편집할 수 있어요.
6. **선착장 > 우편선**: 확인 체크 → `우편선 띄우기`(휴대폰은 공유 창, PC는 이미지 저장 + 캡션 복사) → 인스타그램에 올린 뒤 `게시 완료`.
7. **성과 게시판**: 게시한 카드뉴스의 좋아요·저장·도달을 적어요.

초안 위에 붙는 꼬리표: `Groq`(AI가 씀), `뼈대`(키가 없거나 연결 실패라 소식 요약으로 만든 초안), `예시`.

### 저장에 대해

지금은 모든 데이터가 **이 브라우저(localStorage)** 에만 저장돼요. 다른 기기로 옮기거나 지키려면 **소장실 > 소장 책상 > 백업 내려받기**를 써 주세요. 4단계에서 Supabase로 옮겨요.

      자료 도서관              성과 게시판
  연구원 숙소       [광장]           소장실
       카드뉴스 공방      블로그 서재
  수신소(물레방아)                       선착장
  ≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈ 강 (소식 병이 떠내려와요) ≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈

| 건물          | 직원                    | 눌러볼 사물                             |
| ------------- | ----------------------- | --------------------------------------- |
| 수신소        | 통신원 루미 (헤드셋)    | 수신 모니터: 오늘 소식, 담기            |
| 카드뉴스 공방 | 디자이너 모모 (앞치마)  | 작업 모니터: 카드 편집 / 인쇄기: 이미지 |
| 블로그 서재   | 작가 테오 (동그란 안경) | 원고 책상: 블로그 글, 복사              |
| 선착장        | 선장 바다 (선장 모자)   | 우편선: 게시 확인                       |
| 자료 도서관   | 사서 다온 (카디건)      | 책장: 지난 소식 검색                    |
| 성과 게시판   | 분석가 나래 (스카프)    | 게시판: 좋아요·저장·도달                |
| 연구원 숙소   | 매니저 하리 (명찰)      | 연구원 명부: 직함·이름 편집             |
| 소장실        | 나 (베레모 + 작은 가방) | 소장 책상: 브랜드 설정 / 서랍장: 보관함 |

## 조작

- **방 보기**: 지도에서 방을 누르면 그 방으로 다가가요. 한 번 더 누르면 그 방 연구원이 한마디 해요.
- **일하기**: 방에 들어가면 아래에 나오는 사물 버튼(작업 모니터, 인쇄기…)을 눌러 작업 창을 열어요.
- **지도 옮기기**: 끌어서 옮기고, 휠이나 두 손가락으로 확대·축소해요.
- **빠른 이동**: 오른쪽 위 버튼으로 바로 원하는 건물에 갈 수 있어요.
- `Esc`: 작업 창 닫기, 방에서 나가기.

## 실행하기

```bash
npm install
cp .env.example .env.local   # GROQ_API_KEY를 넣으면 AI가 글을 써요 (없어도 돌아가요)
npm run dev                  # Next.js 앱: http://localhost:3000
npm run typecheck
npm test                     # 자동 회의·동기화·로그인 문지기 (가짜 서버로)
npm run daily                # 자동 회의 한 번 (FORCE=1이면 시간과 상관없이)
npm run preview:build        # 단일 HTML 파일: preview/dist/index.html
npm run feeds:check          # 소식 출처마다 실제로 받아지는지 점검 (GitHub Actions "소식 출처 점검"으로도)
```

미리보기 HTML 파일에서는 저장된 카드의 편집·인쇄가 가능합니다. 새 뉴스 수집·자료 조사·AI 제작은 Next.js 서버와 Groq 연결이 필요해요. 조사 기능은 일반 웹 검색이 아니라 실제 기사·공식 문서·사용자 참고 링크를 읽습니다. 로그인이나 자바스크립트 실행이 필요한 페이지, PDF는 읽지 못할 수 있어요.

> Supabase 값을 넣고 배포하면 로그인한 연구소 주인만 연구소와 `/api/news`·`/api/ai`·`/api/research`를 쓸 수 있어요. Supabase 값 없이 공개 배포하지는 마세요 (누구나 Groq 사용량을 쓸 수 있어요).

## 사용한 것

Next.js, zustand. 화면 글꼴은 Noto Sans KR이에요 (카드뉴스에는 Jua·Black Han Sans도 써요).
지도 그림을 바꾸려면 `src/lab/assets/otter-map.webp`를 같은 구도의 그림으로 바꾸고, 방 자리가 달라졌으면 `src/lab/data/map.ts` 좌표를 맞춰요. 같은 구도로 더 크게 뽑은 그림(예: 3072×2048)이면 좌표는 그대로 두면 되고, 확대해도 덜 흐려요.
