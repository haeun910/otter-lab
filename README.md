# 오터랩 (Otter Lab)

숲속 강가 연구소에서 수달 연구원들이 AI·IT 소식을 모아 **인스타그램 카드뉴스**와 **네이버 블로그 글**을 만드는 3D 작업 공간이에요.
연구소장(나)은 베레모를 쓴 수달이 되어 강가를 걸어 다니고, 건물에 들어가 사물을 눌러 일을 확인해요.

## 지금 되는 것

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 3D 연구소: 본관 하나에 방 9칸 + 선착장, 연구원 8명 | 완료 |
| 2 | 소식 받기, 초안 만들기·고치기, 카드 이미지 인쇄, 게시 기록, 성과 입력, 백업 | 완료 |
| 3 | Groq로 카드뉴스·블로그 글쓰기 (키가 없으면 뼈대 초안) | 완료 |
| 4 | 회의실: 회의 시간에 모여 추천 소식·성과·게시 대기를 보고하고 소장이 결정 | 완료 |
| 5 | Supabase 저장 + 이메일(또는 구글) 로그인, 연구소 주인만 열기 | 완료 (연결은 [SETUP.md](SETUP.md)) |
| 6 | GitHub Actions 매일 자동 회의(묶음 1 + 심층 1) + 텔레그램 알림 | 완료 (연결은 [SETUP.md](SETUP.md)) |
| 7 | 분위기 다듬기 (덜 장난감 같은 그림체·조명·색감) | 다음 |
| 8 | 인스타그램 자동 게시, 성과 수치 자동 수집 | 예정 |

계정을 연결하는 순서는 **[SETUP.md](SETUP.md)** 에 있어요. 연결하기 전에는 지금처럼 이 브라우저에만 저장돼요.

### 하루 작업 흐름

1. **수신소 > 수신 모니터**: `새 소식 받기`로 국내외 피드 9곳에서 최근 48시간 소식을 받아요 (`src/lab/news/feeds.ts`).
2. 만들 소식을 `+`로 담아요. 하나면 **심층 초안**, 2~6개면 **묶음 초안**. 지난 소식은 **자료 도서관**에서 찾아 담아도 돼요.
3. **카드뉴스 공방 > 작업 모니터**: 카드 문구·순서·장수, 캡션, 해시태그를 고쳐요.
4. **블로그 서재 > 원고 책상**: `고치기`로 글을 다듬고, 제목·본문·태그를 복사해 네이버에 붙여 넣어요.
5. **카드뉴스 공방 > 인쇄기**: 카드를 1080×1350 PNG로 뽑아요 (카드를 누르면 한 장만).
6. **선착장 > 우편선**: 확인 체크 → `우편선 띄우기`(휴대폰은 공유 창, PC는 이미지 저장 + 캡션 복사) → 인스타그램에 올린 뒤 `게시 완료`.
7. **성과 게시판**: 게시한 카드뉴스의 좋아요·저장·도달을 적어요.

초안 위에 붙는 꼬리표: `Groq`(AI가 씀), `뼈대`(키가 없거나 연결 실패라 소식 요약으로 만든 초안), `예시`.

### 저장에 대해

지금은 모든 데이터가 **이 브라우저(localStorage)** 에만 저장돼요. 다른 기기로 옮기거나 지키려면 **소장실 > 소장 책상 > 백업 내려받기**를 써 주세요. 4단계에서 Supabase로 옮겨요.

       카드뉴스 공방      블로그 서재
  수신소(물레방아)                       선착장

| 건물 | 직원 | 눌러볼 사물 |
|---|---|---|
| 수신소 | 통신원 루미 (헤드셋) | 수신 모니터: 오늘 소식, 담기 |
| 카드뉴스 공방 | 디자이너 모모 (앞치마) | 작업 모니터: 카드 편집 / 인쇄기: 이미지 |
| 블로그 서재 | 작가 테오 (동그란 안경) | 원고 책상: 블로그 글, 복사 |
| 선착장 | 선장 바다 (선장 모자) | 우편선: 게시 확인 |
| 자료 도서관 | 사서 다온 (카디건) | 책장: 지난 소식 검색 |
| 성과 게시판 | 분석가 나래 (스카프) | 게시판: 좋아요·저장·도달 |
| 연구원 숙소 | 매니저 하리 (명찰) | 연구원 명부: 직함·이름 편집 |
| 소장실 | 나 (베레모 + 작은 가방) | 소장 책상: 브랜드 설정 / 서랍장: 보관함 |

## 조작

- **이동**: 땅을 누르면 걸어가요. 키보드 WASD·방향키도 돼요.
- **들어가기**: 건물이나 간판을 누르면 문 앞까지 걸어가서 들어가요. 문 앞에서 `E`.
- **일하기**: 방 안에서 바닥에 동그라미가 있는 사물(또는 사물 이름표)을 누르면 카메라가 다가가고 작업 창이 열려요.
- **시점**: 바깥에서 끌어서 돌리고, 휠이나 두 손가락으로 확대·축소해요.
- **빠른 이동**: 오른쪽 위 버튼으로 바로 원하는 건물에 갈 수 있어요.
- `Esc`: 작업 창 닫기, 방에서 나가기.

## 실행하기

```bash
npm install
cp .env.example .env.local   # GROQ_API_KEY를 넣으면 AI가 글을 써요 (없어도 돌아가요)
npm run dev                  # Next.js 앱: http://localhost:3000
npm run typecheck
npm test                     # 자동 회의·동기화·로그인 문지기 (가짜 서버로)
npm run daily                # 자동 회의 한 번 (FORCE=1이면 시간과 상관없이)
npm run preview:build        # 단일 HTML 파일: preview/dist/index.html
```

미리보기 HTML 파일은 서버가 없어서 `새 소식 받기`가 안 되고, 초안은 항상 뼈대로 만들어져요. 나머지(편집·인쇄·저장)는 똑같이 돼요.

> Supabase 값을 넣고 배포하면 로그인한 연구소 주인만 연구소와 `/api/news`·`/api/draft`를 쓸 수 있어요. Supabase 값 없이 공개 배포하지는 마세요 (누구나 Groq 사용량을 쓸 수 있어요).
