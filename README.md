# 오터랩 (Otter Lab)

숲속 강가 연구소에서 수달 연구원들이 AI·IT 소식을 모아 **인스타그램 카드뉴스**와 **네이버 블로그 글**을 만드는 3D 작업 공간이에요.
연구소장(나)은 베레모를 쓴 수달이 되어 강가를 걸어 다니고, 건물에 들어가 사물을 눌러 일을 확인해요.

## 지금은 1단계예요

| 단계 | 내용 | 상태 |
|---|---|---|
| 1 | 3D 연구소 (예시 데이터): 강가 지도, 수달 8마리, 방 8개, 클릭 이동, 사물 확대 작업 창 | 완료 |
| 2 | 서버 연결: Supabase(데이터·이미지), 구글 로그인(내 계정만) | 예정 |
| 3 | Groq 무료 AI로 카드뉴스·블로그 글쓰기, 카드 이미지(1080×1350) 렌더링 | 예정 |
| 4 | GitHub Actions로 매일 오전 10시 자동 초안(묶음 1 + 심층 1), 텔레그램 알림 | 예정 |
| 5 | 인스타그램 검토 후 게시, 성과 게시판, 자료 도서관 | 예정 |

1단계의 작업 창은 모두 **예시 데이터**예요. 수신 모니터의 소식은 10월 5일에 실제 RSS에서 모은 제목·요약이고, 카드뉴스·블로그 글은 그 요약만 바탕으로 손으로 쓴 예시예요.

## 연구소 지도

```
      자료 도서관              성과 게시판
  연구원 숙소       [광장]           소장실
       카드뉴스 공방      블로그 서재
  수신소(물레방아)                       선착장
  ≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈ 강 (소식 병이 떠내려와요) ≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈≈
```

| 건물 | 직원 | 눌러볼 사물 |
|---|---|---|
| 수신소 | 통신원 루미 (헤드셋) | 수신 모니터: 오늘 소식, 담기 |
| 카드뉴스 공방 | 디자이너 모모 (앞치마) | 작업 모니터: 카드 편집 / 인쇄기: 이미지 |
| 블로그 서재 | 작가 테오 (동그란 안경) | 원고 책상: 블로그 글, 복사 |
| 선착장 | 선장 바다 (선장 모자) | 우편선: 게시 확인 |
| 자료 도서관 | 사서 다온 (카디건) | 책장: 지난 소식 검색 |
| 성과 게시판 | 분석가 나래 (스카프) | 게시판: 좋아요·저장·도달 |
| 연구원 숙소 | 매니저 하리 (명찰) | 연구원 명부: 직함·이름 편집 |
| 소장실 | 나 (베레모 + 작은 가방) | 소장 책상: 브랜드 설정 / 서랍장: 보관함 |

## 조작

- **이동**: 땅을 누르면 걸어가요. 키보드 WASD·방향키도 돼요.
- **들어가기**: 건물이나 간판을 누르면 문 앞까지 걸어가서 들어가요. 문 앞에서 `E`.
- **일하기**: 방 안에서 바닥에 동그라미가 있는 사물(또는 사물 이름표)을 누르면 카메라가 다가가고 작업 창이 열려요.
- **시점**: 바깥에서 끌어서 돌리고, 휠이나 두 손가락으로 확대·축소해요.
- **빠른 이동**: 오른쪽 위 버튼으로 바로 원하는 건물에 갈 수 있어요.
- `Esc`: 작업 창 닫기, 방에서 나가기.

## 실행하기

```bash
npm install
npm run dev            # Next.js 앱: http://localhost:3000
npm run preview:build  # 1단계 확인용 단일 HTML 파일: preview/dist/index.html
```

## 폴더 구조

```
app/                    Next.js 앱 (2단계부터 서버 기능이 들어가요)
src/lab/
  OtterLab.tsx          3D 캔버스, 장면 전환, 키보드·시점 조작
  store.ts              상태 (장면, 작업 창, 직원 이름, 브랜드 설정, 카드 편집)
  data/buildings.ts     건물 8채, 방 안 사물, 브랜드 색
  data/demo.ts          1단계 예시 데이터 (소식, 카드, 블로그, 성과, 보관함)
  nav/grid.ts           A* 길찾기
  three/Otter.tsx       수달 캐릭터 (토이 스타일, 소품 8종, 걷기·일하기·손 흔들기)
  three/Outside.tsx     강가 지도, 산책하는 직원
  three/Building.tsx    건물과 건물별 장식 (물레방아, 잔교, 굴뚝 연기…)
  three/Nature.tsx      강, 다리, 나무, 꽃, 갈대, 소식 병
  three/Room.tsx        방 내부, 직원, 사물 클릭
  three/Furniture.tsx   모니터 책상, 인쇄기, 책장, 우편선…
  three/labels.tsx      3D 위 한글 라벨 위치 맞추기
  ui/                   HUD, 빠른 이동, 작업 창, 카드뉴스 미리보기
preview/                1단계 링크 공유용 Vite 단일 파일 빌드
```
